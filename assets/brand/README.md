# Pactmark brand assets

The canonical symbol is [`pactmark-logo.svg`](pactmark-logo.svg). It preserves
the supplied artwork while adding an accessible title and description.

## Core palette

| Role         | Value     | Use                                |
| ------------ | --------- | ---------------------------------- |
| Pactmark red | `#D11F26` | Primary mark and decisive accents  |
| Ink          | `#17191F` | Primary text and dark surfaces     |
| Paper        | `#FFFFFF` | Mark foreground and light surfaces |
| Mist         | `#F5F3F1` | Quiet background panels            |

## Usage

- Preserve the square aspect ratio and internal geometry.
- Keep clear space of at least one eighth of the mark's width on all sides.
- At small sizes, use the full red square; do not extract or redraw the white
  geometry.
- Provide meaningful alt text in editorial contexts and empty alt text when an
  adjacent heading already names Pactmark.
- Do not recolor, stretch, rotate, add effects, or combine the symbol into
  another logo.

Name and logo permissions are defined in the repository's
[name and logo policy](../../TRADEMARKS.md). The Apache-2.0 license does not by
itself grant rights to present a modified distribution as official Pactmark.
