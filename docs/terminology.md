---
title: Terminology
description: Canonical Pactmark API names and their documentation meanings.
---

> Compatibility: Pactmark 0.1.x.

API names remain English in every locale. `AgentDefinition` is the compiled agent
contract; `WorkOrder` is authorized bounded work; a run is its event-derived
execution; `Artifact` is content-addressed output; `Verifier` checks exact bytes;
and `EvidenceRecord` carries selected redacted claims.

Status labels distinguish locally evidenced behavior, experimental or pilot behavior,
and future work. They are not maturity, certification, or support badges.
