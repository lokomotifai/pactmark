> Compatibility: Pactmark 0.1.x.

## Katkı akışı

`CONTRIBUTING.md`, product principles ve ilgili ADR/package README'lerini okuyun.
Dar kapsamlı değişiklik, deterministic test ve kullanıcı davranışı için Changeset ekleyin.
Commit DCO sign-off taşır; packed davranış yalnız workspace link ile kabul edilmez.

## Güvenlik bildirimi

Vulnerability için public issue açmayın. `SECURITY.md` içindeki doğrulanmış private
kanalı kullanın. GitHub Private Vulnerability Reporting bu repository için açıktır;
exploit detayını public issue veya pull request'e taşımayın.

## Komünite Agent Lab

Komünite Agent Lab pattern gönderisi exact definition/tool/policy/verifier digest,
örnek WorkOrder, redakte EvidenceRecord, başarısızlıklar ve güvenlik incelemesi içerir.
Model veya yazar kendi pattern'ını sertifikalandıramaz.
